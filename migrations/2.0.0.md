# 2.0.0 — Organization rules move to profiles (no project file changes)

## Applies if
Always (nothing to change in the project; only the version is recorded).

## Changes
1. None in the project. Existing `CLAUDE.md`, `REVIEW.md` and
   `.claude/settings.json` keep working as they are, whatever their language:
   `check.sh` accepts section names in English or Spanish.
2. On the **machine**, not the project: since 2.0.0 the core ships no
   organization rules. A machine that relied on them must be reinstalled with
   `install.sh --profile <dir>`; `install.sh` refuses to upgrade a 1.x machine
   without `--profile` or `--no-profile`.

## Check
`~/.claude/workflow/profile` names the expected profile, and `check.sh` →
`PASS  workflow up to date (2.0.0)`.
